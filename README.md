# 🌴 Explore Sri Lanka – E-Tourism Management System

**Explore Sri Lanka** is a responsive E-Tourism Management System designed to provide users with an interactive platform for discovering Sri Lankan destinations, exploring tour packages, viewing accommodation information, and managing travel bookings.

The system provides an engaging tourism experience through a modern interface, destination-focused content, user authentication, and database-driven management features.

---

## 📌 Project Overview

The **Explore Sri Lanka E-Tourism Management System** was developed as a full-stack web application to simplify the process of discovering and planning travel experiences in Sri Lanka.

Users can explore popular destinations, learn about local attractions, browse tour and accommodation options, create accounts, and complete booking workflows through an easy-to-use interface.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/explore-sri-lanka.git
```

### 2. Open the Project

Open the project folder using your preferred development environment.

### 3. Configure the Database

Create a MySQL database and import the project's SQL database file.

Update the database configuration with your local credentials:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "explore_sri_lanka";
```

### 4. Run the Application

If using XAMPP:

1. Start **Apache**
2. Start **MySQL**
3. Place the project inside the `htdocs` folder.
4. Open your browser.
5. Navigate to:

```text
http://localhost/explore-sri-lanka/
```
